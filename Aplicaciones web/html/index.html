DOCKER

¿Qué es docker?

Docker es una plataforma que permite desarrollar, empaquetar, distribuir y ejecutar aplicaciones dentro de contenedores.


Un contenedor incluye la aplicación junto con sus dependencias y configuraciones necesarias para ejecutarse de forma consistente en diferentes entornos.


La idea principal es:

Construye una vez y ejecuta de forma consistente en cualquier entorno compatible con Docker.

¿Para qué sirve?

Docker facilita:

  • Desarrollo de aplicaciones.
  • Pruebas en entornos aislados.
  • Despliegue de aplicaciones.
  • Distribución de software.
  • Creación de entornos reproducibles.
  • Ejecución de múltiples servicios en un mismo equipo.

Por ejemplo, puedes tener:

  • Node.js
  • Aplicación
  • PostgreSQL
  • Redis

Cada componente puede ejecutarse en su propio contenedor.

Conceptos fundamentales

Concepto Descripción
Imagen Plantilla utilizada para crear contenedores.
Contenedor Instancia ejecutable de una imagen.
Dockerfile Archivo con instrucciones para construir una imagen.
Registry Almacén de imágenes, como Docker Hub.
Volumen Permite almacenar datos fuera del ciclo de vida del contenedor.
Red Permite la comunicación entre contenedores.

Docker vs. Máquina virtual

Docker Máquina virtual
Comparte el kernel del sistema anfitrión Tiene un sistema operativo completo
Consume menos recursos Consume más recursos
Inicio rápido Inicio más lento
Contenedores ligeros Máquinas virtuales más pesadas
Aislamiento a nivel de procesos Aislamiento mediante virtualización
