DOCKER COMPOSE

¿Qué es Docker Compose?

Docker Compose es una herramienta que permite definir, configurar y ejecutar aplicaciones formadas por múltiples contenedores.


La configuración de los servicios se almacena en un archivo llamado compose.yaml, donde se pueden establecer imágenes, puertos, redes, volúmenes, variables de entorno y dependencias.

¿Para qué sirve?

  • Gestionar varios contenedores como una sola aplicación.
  • Centralizar la configuración en un archivo.
  • Crear redes para permitir la comunicación entre servicios.
  • Administrar volúmenes para conservar datos.
  • Iniciar y detener todos los servicios con pocos comandos.

Archivo compose.yaml

El archivo compose.yaml describe los servicios que forman parte de la aplicación.

En él se puede indicar:

  • La imagen que utilizará cada servicio.
  • Los puertos.
  • Las variables de entorno.
  • Los volúmenes.
  • Las dependencias entre servicios.

Servicios

En Docker Compose, cada servicio representa un componente de la aplicación y normalmente se ejecuta en su propio contenedor.

Servicio Función
Backend Ejecuta la lógica de la aplicación
MySQL Almacena los datos
phpMyAdmin Permite administrar MySQL mediante una interfaz web

Los servicios pueden comunicarse entre sí mediante la red creada por Docker Compose.

Ejemplo

services:

  backend:
    image: mi-backend
    ports:
      - "3000:3000"
    depends_on:
      - mysql

  mysql:
    image: mysql:8
    environment:
      MYSQL_ROOT_PASSWORD: root
      MYSQL_DATABASE: app
    volumes:
      - mysql_data:/var/lib/mysql

  phpmyadmin:
    image: phpmyadmin
    ports:
      - "8080:80"
    environment:
      PMA_HOST: mysql
    depends_on:
      - mysql

volumes:
  mysql_data:

En ejecucion:

  • backend depende de mysql.
  • phpmyadmin depende de mysql.
  • mysql_data permite conservar los datos de MySQL.
  • Los servicios pueden comunicarse utilizando la red de Compose.

Comandos básicos

Accion Comando Descripcion
Iniciar los servicios docker compose up Crea e inicia los servicios definidos en compose.yaml.
Iniciar en segundo plano docker compose up -d Ejecuta los servicios sin mantenerlos ocupando la terminal.
Ver los servicios docker compose ps Muestra el estado de los servicios del proyecto.
Detener los servicios docker compose stop Detiene los servicios sin eliminarlos.
Detener y eliminar docker compose down Detiene y elimina los contenedores y redes creados por Compose.
Eliminar docker rm nombre_contenedor Elimina un contenedor detenido.

Ventaja principal

Docker Compose facilita la administración de aplicaciones que utilizan varios contenedores, ya que permite definir sus servicios y configuración en un solo archivo.


De esta manera, es posible iniciar, detener y administrar los contenedores de un proyecto de forma conjunta mediante comandos sencillos.
