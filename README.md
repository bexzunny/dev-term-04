## Descripción general

Dev Term 04 es un repositorio académico que reúne prácticas, ejercicios, implementaciones y proyectos correspondientes al cuarto cuatrimestre de Desarrollo de Software Multiplataforma. El contenido se organiza por asignatura y unidad para facilitar su consulta y revisión.

El repositorio documenta la aplicación práctica de los conocimientos del cuatrimestre: desde la construcción de interfaces web hasta la implementación de estructuras de datos y algoritmos en Java. El historial de Git permite observar cómo han evolucionado las actividades y funcionalidades a lo largo del periodo.

El trabajo continúa en desarrollo y se ampliará conforme avance el cuatrimestre y se incorporen nuevas prácticas y proyectos.

## Asignaturas

### Aplicaciones Web

La asignatura reúne proyectos y prácticas orientados a la construcción de páginas y sitios web. El trabajo parte de la estructura y el estilo con HTML y CSS, y avanza hacia la interacción con JavaScript.

**Contenidos trabajados**

- Estructura semántica, encabezados, enlaces, imágenes, listas, formularios y navegación entre páginas.
- Hojas de estilo, selectores, variables CSS, Flexbox, transiciones, animaciones y diseño adaptativo con media queries.
- Manipulación del DOM, eventos, cambio de tema visual, efectos de interacción y validación de formularios.
- Uso de recursos externos como Bootstrap, AOS, SweetAlert2 y JustValidate en proyectos específicos.
- Documentación de apoyo sobre sentencias SQL y una guía de referencia de Git y GitHub.

**Proyectos representativos**

- `Unidad-1/Proyecto-u1/Aplicaciones-web-proyecto-u1/`: sitio informativo multipágina sobre Docker, con secciones de conceptos, contenedores y Docker Compose.
- `Unidad-2/OddJobs/`: sitio multipágina con portada, catálogo, taller y sección "nosotros"; incorpora componentes de Bootstrap, animaciones con AOS, SweetAlert2 y validación con JustValidate.
- `Unidad-2/landing_page/`: página de presentación sobre Git con formulario y validación implementada desde JavaScript.
- `Unidad-1/Proyecto-5/`: página con cambio de tema, efectos sobre imágenes y diseño adaptable.

### Estructuras de Datos

La asignatura se centra en la implementación de estructuras de datos y algoritmos en Java. Los ejercicios se organizan por unidad y combinan arreglos, matrices, recursividad, ordenamientos y listas enlazadas, con entrada de datos mediante `JOptionPane`.

**Contenidos trabajados**

- Arreglos y matrices: recorrido, suma, operaciones y ejercicios aplicados.
- Recursividad: factorial, exponenciación y multiplicación mediante llamadas recursivas.
- Algoritmos de ordenamiento: burbuja, ordenamiento rápido y ordenamiento por montículos.
- Listas enlazadas: nodos, listas simples y dobles; inserción al inicio, al final y por posición, eliminación, búsqueda, modificación y recorrido.
- Operaciones sobre listas: suma, producto, números pares, primos e impares, y conteo de elementos.
- Modelado de ejercicios con clases: empleados, dispositivos electrónicos y transportes de carga.

**Implementaciones representativas**

- `Unidad_1/Metodos_ordenacion/`: implementaciones de ordenamiento burbuja, rápido y por montículos.
- `Unidad_2/Clase_12_10_16/ListaSimple.java`: lista simplemente enlazada con operaciones de inserción, eliminación, búsqueda y recorrido.
- `Unidad_2/Clase_04_11_26/ListaDoble.java`: lista doblemente enlazada con recorridos en ambos sentidos.
- `Unidad_2/Ejercicio_06_11_26/ListaTransportes.java`: gestión de transportes de carga mediante una lista enlazada.

- Bootstrap 5, AOS, SweetAlert2 y JustValidate: bibliotecas externas utilizadas en proyectos de la Unidad 2.

## Control de versiones

El proyecto utiliza Git para registrar los cambios y mantener un historial organizado del desarrollo. Los commits buscan describir actividades, funcionalidades y avances técnicos, de modo que el historial permita reconstruir la evolución del trabajo.

Los historiales de Aplicaciones Web y Estructuras de Datos forman parte del repositorio principal. No se declara una estrategia de ramas ni un flujo de trabajo colaborativo, ya que no forman parte del estado actual del proyecto.

## Objetivos académicos y técnicos

- Consolidar el desarrollo de interfaces web mediante HTML, CSS y JavaScript.
- Aplicar la lógica de programación en la resolución de ejercicios y problemas.
- Implementar estructuras de datos y algoritmos, incluyendo arreglos, matrices, recursividad, ordenamientos y listas enlazadas.
- Construir aplicaciones y páginas web funcionales, con navegación, estilos y validación.
- Organizar el código y la documentación por asignatura, unidad y actividad.
- Utilizar herramientas de desarrollo y control de versiones para mantener un historial claro.
- Documentar el proceso de aprendizaje y facilitar la revisión del trabajo realizado.
